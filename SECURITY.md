# Security and privacy

Dreamscape only targets the desktop web interface at `chatgpt.com`. The userscript is intended for visual customization, not for interacting with accounts or collecting messages.

- Wallpaper files are processed client-side and stored in IndexedDB on `chatgpt.com`.
- Preferences are stored in localStorage on `chatgpt.com`.
- No analytics, telemetry, user accounts or remote wallpaper uploads are included.
- Never share personal conversations, tokens, extension secrets or private images in public bug reports.

To report a vulnerability, contact the maintainer privately through GitHub rather than opening a public issue with exploitation instructions.

**Important:** Browser extensions/userscripts are privileged in the page context. Review the source, use a trusted userscript manager and install updates from the official repository only. Dreamscape is community-maintained and unaffiliated with OpenAI.
