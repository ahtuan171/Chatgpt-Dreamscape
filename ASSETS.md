# Artwork and asset notes

Dreamscape currently bundles **five original wallpapers** and **Victor**, the gray pixel cat.

| Wallpaper | Origin |
| --- | --- |
| Moonlit Castle | Original AI-assisted illustration created for this project |
| Midnight Tulips | Original AI-assisted illustration created for this project |
| Prince & Princess | Original AI-assisted moonlit romantic silhouette made for this project |
| Arcane Library | Original AI-assisted pixel-art fantasy library made for this project |
| The Silent King | Original AI-assisted cinematic monochrome chess wallpaper made for this project |

The other eight previously bundled wallpapers, including Moonlit Village, have been removed from the public collection. The procedural wallpaper generator has also been removed to avoid recreating retired art.

- `assets/pets/victor/*.webp`: Victor, the gray pixel cat, provided by the project creator and adapted into idle, walk and sleep animation frames.

**Asset terms:** The MIT license applies to project *code*, not these visual assets. Bundled images may be used and redistributed **with Dreamscape**; extracting or reselling them separately is not automatically permitted. Contributors should not add third-party art without clear redistribution rights.

The public bundle intentionally excludes personal Spidey art and third-party wallpapers (including recognizable media characters and photos with unverified licenses). Users can import their own images privately; uploads stay in their browser and are not published to this repository.

If you believe an asset infringes your rights, please open an issue identifying the asset and relevant rights information.
